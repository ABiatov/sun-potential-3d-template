# Add / Remove layers

## Официальный кейс
- Slug: `map-add-remove-layers`

## Краткое описание (official)
Add and remove layers in a Map.

## Расширенное описание (official longdesc)
Use the `addLayer()` and `removeLayer()` methods to add and remove layers in a Map.
