# Security Policy

## Reporting a Vulnerability

If you believe you have found a security vulnerability in this project, please do not open a public issue.

Instead, report it privately by contacting the maintainers.

Please include:

- a description of the issue
- steps to reproduce
- potential impact
- suggested fix, if available

We will review the report and respond as soon as possible.

## Scope

This repository contains the public viewer/template application only.

Please note:

- no production backend is included in this repository
- no proprietary analysis engine is included in this repository
- demo data is provided for development purposes only

## Supported Versions

Security updates are currently provided for the latest version of the repository.

## Disclosure Policy

Please allow time for the issue to be reviewed and fixed before disclosing it publicly.


Please report vulnerabilities by email to: info@sun-potential-3d.com
